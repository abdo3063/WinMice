## ⚙️ What Does WinMice Do?

Here are the main things WinMice does for you:

### 📜 Windows-Style Scrolling
On Windows, when you scroll the wheel down, the page moves down. On a Mac, it's often set to "natural" scrolling, which means moving the wheel down moves the page up. WinMice changes this so it feels exactly like your old Windows mouse.

### ↔️ Side Buttons That Work
Most computer mice have two side buttons. These are normally used for going back and forward in web browsers and file folders. On Windows, these work automatically. On a Mac, they might not work at all or do something unexpected. WinMice makes these buttons do what you expect: one goes back, the other goes forward.

### 🔄 Consistent Behavior
WinMice makes sure the same mouse action always does the same thing, no matter which app you're using. This means less confusion and more productivity because you'll never have to think about what your mouse will do next.
