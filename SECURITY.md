# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Do **not** open a public GitHub issue for security reports.

Use GitHub private vulnerability reporting:

https://github.com/anibalribeiro/WinMice/security/advisories/new

If that form is unavailable, email Aníbal Ribeiro at **anibalcezar@live.com** with:

- A description of the issue
- Steps to reproduce
- Affected version or commit
- Impact, especially anything involving Accessibility, event taps, or local privilege

You should get an acknowledgement within 7 days, then a fix or a status update as soon as one is ready. Please wait for that before disclosing the issue publicly.
