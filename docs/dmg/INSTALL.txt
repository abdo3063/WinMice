WinMice {{VERSION}}
==================

Install
-------
1. Drag WinMice to the Applications folder (in this window).
2. Eject this disk image.
3. Open WinMice from Applications.
4. Grant Accessibility when asked (WinMice → Settings → Permissions).

Homebrew
--------
  brew tap anibalribeiro/winmice
  brew trust anibalribeiro/winmice
  brew install --cask winmice
